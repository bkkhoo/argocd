= OpenShift Serverless

The Red Hat OpenShift Serverless operator provides a collection of APIs that enables containers, microservices and functions to run "serverless". Serverless applications can scale up and down (to zero) on demand and be triggered by a number of event sources.

== Installing the Chart

The install the chart:

[source,bash]
----
helm install --name project-request-template helm-chart/openshift-serverless
----

== Uninstalling the Chart

To uninstall/delete the chart deployment:

[source,bash]
----
helm delete openshift-serverless
----

== Configuration

The following table lists the configurable parameters/values of this Helm chart and their default values.

[cols="2,1,4", options="header"]
|===
| Parameter
| Default
| Description

| serviceMeshIntegration
| true
| Enable/Disable OpenShift Serverless integration with OpenShift Service Mesh. Note that the value is a string NOT boolean.
|===
