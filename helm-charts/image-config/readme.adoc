= Configure OpenShift Monitoring

Configure the cluster-wide policies for container image imports, registry access, and trust configurations, allowing administrators to restrict which registries can be used for importing images or pulling container runtime images.

== Installing the Chart

The install the chart:

[source,bash]
----
helm install --name openshift-image-config helm-chart/openshift-image-config
----

== Configuration

The following table lists the configurable parameters/values of this Helm chart and their default values.

[cols="2,1,4", options="header"]
|===
| Parameter
| Default
| Description

| additionalRegistries
| Empty list
| List of additional container image registries to allow.
|===
