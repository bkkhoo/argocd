= Configure OpenShift oAuth Token Timeout

The OpenShift internal OAuth server allows configuration of access token lifetime and inactivity timeouts via the OAuth Custom Resource (CR) and OAuthClient objects.

== Installing the Chart

The install the chart:

[source,bash]
----
helm install --name openshift-oauth helm-chart/openshift-oauth
----

== Configuration

The following table lists the configurable parameters/values of this Helm chart and their default values.

[cols="2,1,4", options="header"]
|===
| Parameter
| Default
| Description

| env
| prod
| Environment of the cluster.

| accessTokenMaxAgeSeconds.dev
| 86400
| Set the maximum lifetime of the access token for `dev` environment.

| accessTokenMaxAgeSeconds.uat
| 14400
| Set the maximum lifetime of the access token for `uat` environment.

| accessTokenMaxAgeSeconds.prod
| 14400
| Set the maximum lifetime of the access token for `prod` environment.

| accessTokenInactivityTimeout.dev
| 86400s
| Set the inactivity timeout of the access token for `dev` environment.

| accessTokenInactivityTimeout.uat
| 1800s
| Set the inactivity timeout of the access token for `uat` environment.

| accessTokenInactivityTimeout.prod
| 1800s
| Set the inactivity timeout of the access token for `prod` environment.
|===
