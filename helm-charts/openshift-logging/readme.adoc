= OpenShift Logging

The Red Hat OpenShift Logging Operator orchestrates log collection and forwarding to Red Had managed log stores and other third-party receivers.

== Installing the Chart

The install the chart:

[source,bash]
----
helm install --name openshift-compliance helm-chart/openshift-logging
----

== Uninstalling the Chart

To uninstall/delete the chart deployment:

[source,bash]
----
helm delete openshift-logging
----
