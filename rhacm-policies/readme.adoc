= About this Kustomize Deployment

RHACM governance policies, the polices are deployed to **global hub** and **managed hubs** only.

== RHACM Policies

=== Common Policies

These policies are common to both global hub and managed hubs.

[cols="2,1,3,3", options="header"]
|===
| Policy | Remediation Action | Placement | Description

| config-remove-kubeadmin
| Enforce
| All OpenShift clusters.
| Ensure `kubeadmin` user is removed.

| config-rhacs-secured-cluster
| Enforce
| All OpenShift clusters, except `local-cluster` and cluster with `managed-hub` label.
| Deploy RHACS operator, SecuredCluster and cluster registration secret.

| monitor-cluster-operators
| Inform
| All OpenShift clusters.
| Monitor cluster operators; status should be `Available=true`, `Degraded=false`.

| monitor-nodes
| Inform
| All OpenShift clusters.
| Monitor for nodes that exhibit MemoryPressure, DiskPressure, PIDPressure, or a NotReady state.

| monitor-etcd-encryption
| Inform
| All OpenShift clusters.
| Verify that ETCD encryption has completed.

| monitor-rhacs-secured-clusters
| Inform
| All OpenShift clusters.
| Monitor RHACS SecuredCluster deployments.

| monitor-role-with-wildcard-permissions
| Inform
| All OpenShift clusters.
| Detect namespaced Role with wildcard permissions (`apiGroups: ["*"]`, `resources: ["*"]`, `verbs: ["*"]`).

| monitor-privileges-scc-binding
| Inform
| All OpenShift clusters.
| Monitor for namespaces with RoleBindings that grant access to `privileged` Security Context Constraint.

| monitor-terminating-namespaces
| Inform
| All OpenShift clusters.
| Monitor for namespaces stuck in the Terminating state.

| monitor-install-plans
| Inform
| All OpenShift clusters.
| Monitor InstallPlans that are pending approval.

| monitor-container-oom-killed
| Inform
| All OpenShift clusters.
| Monitor for containers that exceed their defined memory limit and are killed by the Linux kernel's Out-Of-Memory killer (`OOMKilled`).

| monitor-container-crash-loop-backoff
| Inform
| All OpenShift clusters.
| Monitor for containers that are repeatedly crashing and restarting (`CrashLoopBackOff`).

| monitor-container-image-pull-backoff
| Inform
| All OpenShift clusters.
| Monitor for pods where the kubelet repeatedly fails to pull the required container image from a registry (`ImagePullBackOff`).

| monitor-persistent-volume
| Inform
| All OpenShift clusters.
a| Monitor PersistentVolume (PV) state:

- `Failed`: PV failed to be correctly recycled or deleted after being released from a claim.
- `Released`: For a PersistentVolume with `spec.persistentVolumeReclaimPolicy: Retain`, once the associated PersistentVolumeClaim is deleted, an administrator must manually intervene to remove the claimRef field from the PV specification to make the volume available again.

| monitor-persistent-volume-claim
| Inform
| All OpenShift clusters.
| Monitor PersistentVolumeClaims that are not in `Bound` state.

| monitor-default-storage-class
| Inform
| All OpenShift clusters.
| Monitor to ensure only one default StorageClass.

| monitor-operator-group
| Inform
| All OpenShift clusters.
| Monitor namespaces that have more than one OperatorGroup.

| monitor-failed-cronjob
| Inform
| All OpenShift clusters.
| Monitor CronJobs  that failed their last scheduled run.

| monitor-openshift-route
| Inform
| All OpenShift clusters.
| Monitor OpenShift routes that are not admitted, such as when `spec.host` is already claimed by another route in the cluster.

| certificate-status
| Inform
| All OpenShift clusters.
| Monitor TLS certificates of namespaces (openshift-gitops, openshift-ingress, openshift-ingress-operator, openshift-pipelines, stackrox); triggers a violation if a certificate expires in 15 days or fewer.
|===

=== Global Hub Policies

These policies are for global hub only.

[cols="2,1,3,3", options="header"]
|===
| Policy | Remediation Action | Placement | Description

// | 00-monitor-policy-report
// | Inform
// | `local-cluster` and all OpenShift cluster with `managed-hub` label.
// | Monitor PolicyReports that aggregate and display governance and security violations across managed clusters.

| config-argocd-repo-secrets
| Enforce
| All clusters with `managed-hub` label.
| Ensure ArgoCD repo secrets are distributed to managed hubs' `openshift-gitops` namespace.

| monitor-managed-clusters
| Inform
| `local-cluster` and all OpenShift cluster with `managed-hub` label.
| Monitor ManagedCluster Availability on global hub and managed hubs.

| monitor-managed-hubs-local-cluster
| Inform
| All OpenShift clusters with `managed-hub` label.
| Monitor managed hub with `local-cluster`; no managed hub should have `local-cluster`.

| monitor-multicluster-global-hub-agent
| Inform
| All clusters with `managed-hub` label.
| Monitor multicluster global hub agent, the agent synchronizes data with a central multicluster global hub cluster.

| monitor-openshift-gitops
| Inform
| `local-cluster` and all OpenShift cluster with `managed-hub` label.
| Monitor OpenShift GitOps deployments.

| monitor-argocd-application-set
| Inform
| `local-cluster` and all OpenShift cluster with `managed-hub` label.
| Monitor ArgoCD ApplicationSets.

| monitor-rhacs-central
| Inform
| `local-cluster` and all OpenShift cluster with `managed-hub` label.
| Monitor RHACS Central and SecuredClusters deployments.
|===
