= ArgoCD Applications and ApplicationSets

[cols="2,1,3,3", options="header"]
|===
| Name | Type | Destination Cluster(s) | Description

| 00-global-hub-app-of-apps
| Application
| in-cluster
| Global hub app-of-apps.

| 00-managed-hub-app-of-apps
| Application
| in-cluster
| Managed hubs app-of-apps.

| 01-managed-hub-bootstrap
| ApplicationSet
| All OpenShift clusters with `managed-hub` label for `dev`\|`uat`\|`prod` environments.
| Deploy OpenShift GitOps, RHACM, and managed hubs app-of-apps on managed hubs.

| cluster-config
| ApplicationSet
| All OpenShift clusters without `managed-hub` label and the `in-cluster`.
| Cluster configurations (disable self provisioner, disable insights/telemetry services, OperatorHub, etc,)

| mandatory-operators
| ApplicationSet
| All OpenShift clusters without `managed-hub` label and the `in-cluster`.
a| Deploy the following operators:

- penShift Compliance
- OpenShift Pipelines
- OpenShift Web Terminal

| openshift-serverless
| ApplicationSet
| All OpenShift clusters without the `managed-hub` label but with the `openshift-serverless` label.
| Deploy OpenShift Serverless.

| openshift-service-mesh
| ApplicationSet
| All OpenShift clusters without the `managed-hub` label but with the `openshift-service-mesh` label.
| Deploy OpenShift Service Mesh.

| rhacm-policies
| Application
| in-cluster
| Deploy RHACM Governance Policies to global-hub and managed-hubs.

| rhacs-central
| Application
| in-cluster
| Deploy RHACS Central and SecuredCluster tp global-hub and managed-hub.

| rhacs-secured-cluster
| ApplicationSet
| All OpenShift clusters, excluding `local-cluster` and any cluster with `managed-hub` label.
| Deploy RHACS SecuredCluster in global-hub and managed-hub.

| test-app
| ApplicationSet
| All OpenShift clusters without the `managed-hub` label but with the `test-app` label.
| Deploy dummy test application.
|===
